SpatialHand Studio

Renderer: Canvas 2D WebXR: checking

Inspect and manipulate a 25-joint hand rig in a curved window layout

Zero build step, no external runtime. On a headset, the app requests immersive-ar or immersive-vr with hand-tracking and local-floor when the browser reports support. On desktop, the hand rig, curved guides and windows are drawn with Canvas 2D perspective projection. Joint samples pass through a documented 1-Euro filter and a hysteresis pinch state machine. Readouts distinguish joint samples, render timing and the posture model.
Three desktop drawing styles. No optical see-through or passthrough hardware is used.

Posture comparison

      

        The model uses a two-segment quasi-static shoulder moment. It compares one rested posture with one
        elevated posture at a fixed 75 kg reference mass. It does not measure muscle activation, fatigue,
        comfort, task accuracy or completion time. The 6 s animation only recomputes the algebra.
      

      

        M = g · (m_ua · r_ua · sin(a) + m_fa · (L_ua · sin(a) + r_fa · sin(b))). Rested: a = 14 deg,
        b = 20.4 deg, 2.99 N·m. Elevated: a = 58 deg, b = 62 deg, 9.46 N·m. Difference: 68.4%.
        Segment fractions and centre of mass ratios follow Drillis and Contini anthropometry.
